# Deploying Outsider

Two parts:
- **Backend** (`roamly-backend` branch): an always-on Node server on Render. It also runs live chat (Socket.IO) and the hourly creator rewards.
- **Frontend** (`roamly-frontend` branch): a static site on Vercel.

## 1. Database (MongoDB Atlas)
1. Create a cluster, then a database user.
2. Under Network Access, allow `0.0.0.0/0` (Render IPs change).
3. Copy the connection string and add `/outsider` before the `?`.

## 2. Backend on Render
Go to Render, then New → Blueprint, pick the repo and the `roamly-backend` branch. Render reads `render.yaml`. Then fill in:

| Variable | Value |
|---|---|
| `MONGODB_URI` | Atlas connection string |
| `JWT_SECRET` | generated by Render automatically (or `openssl rand -hex 32`) |
| `CLIENT_URL` | your frontend URL, e.g. `https://outsider.ng` |
| `CLIENT_ORIGINS` | same URL(s), comma-separated (add the `*.vercel.app` URL too if you use it) |
| `API_URL` | this backend's URL, e.g. `https://api.outsider.ng` |
| `ADMIN_EMAIL` | first admin login (default `admin@gmail.com`) |
| `ADMIN_PASSWORD` | first admin password (default `12345678`), change it in Admin → Platform settings |
| `BREVO_API_KEY` | Brevo → SMTP & API → API keys |
| `MAIL_FROM_EMAIL` | a sender verified in Brevo, e.g. `hello@outsider.ng` |
| `MAIL_FROM_NAME` | `Outsider` |
| `PAYSTACK_SECRET_KEY` | Paystack → Settings → API keys (`sk_live_…`) |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | Google Cloud → Credentials → OAuth client (Web) |
| `CLOUDINARY_CLOUD_NAME` / `CLOUDINARY_API_KEY` / `CLOUDINARY_API_SECRET` | Cloudinary dashboard |

On first start the server:
- creates the admin login;
- creates the starter places, subscription plans and the summer top reward;
- creates the plans on Paystack, if the key is set.

Check that `https://<api>/health` returns `{"ok":true,"db":true}`.

### Hook up the services
- **Paystack:**
  - Settings → API Keys & Webhooks.
  - Webhook URL: `https://<api>/v1/billing/webhook`.
- **Google OAuth:**
  - Authorised redirect URI: `https://<api>/v1/auth/google/callback`.
  - Authorised JavaScript origin: your frontend URL.
- **Brevo:** verify your sending domain (SPF/DKIM) so emails don't land in spam.

## 3. Frontend on Vercel
Go to Vercel, then New Project, choose the repo, and set the Production Branch to `roamly-frontend`.

| Variable | Value |
|---|---|
| `VITE_API_URL` | backend URL, e.g. `https://api.outsider.ng` (no trailing slash) |
| `VITE_GOOGLE_MAPS_API_KEY` | optional: Google Maps JavaScript API key (restrict it to your domain). Without it the map uses OpenStreetMap. |
| `VITE_GOOGLE_MAP_ID` | optional: Map ID for styled Google maps |

## 4. Use one domain for both (recommended)
Put the app on `outsider.ng` and the API on `api.outsider.ng`.
- The login cookie is cross-site when the app is on `vercel.app` and the API is on `onrender.com`.
- Safari and iOS block those cookies, so logins would not stick there.

## 5. After deploying
1. Log in with `ADMIN_EMAIL` / `ADMIN_PASSWORD`.
2. Go to Admin → Platform settings and change the admin password.
3. Set your ad prices and rewards on the same page.
4. Run one real ₦ ad-credit purchase and one plan subscription to confirm the Paystack webhooks arrive.
